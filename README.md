# 🤖 AI Resume Analyzer Pro

An AI-powered Resume Analyzer built using **Python, Flask, Machine Learning, and NLP** that evaluates resumes, calculates ATS scores, extracts candidate information, matches resumes with job descriptions, and generates professional PDF reports.

---

## 🌐 Live Demo

**Live Website:**
https://ai-resume-analyzer-swng.onrender.com

---

## 📌 Features

* 🔐 User Registration & Login
* 📄 Resume Upload (PDF)
* 📖 PDF Text Extraction
* 📊 ATS Score Calculation
* 🎯 Job Description Matching
* 🧠 Skill Extraction
* ❌ Missing Skills Detection
* 🤖 AI Resume Suggestions
* 💼 Job Recommendations
* 👤 Candidate Information Extraction
* 📜 Resume History
* 📄 Resume Preview
* 📥 PDF Report Generation
* 📈 Dashboard
* ⚠️ Error Handling (404 & 500)

## 🚀 Installation

```bash
git clone https://github.com/gayathri499/AI-Resume-Analyzer.git

cd AI-Resume-Analyzer

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
